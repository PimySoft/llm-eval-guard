# Plans

## Free plan

The Free plan includes 15GB of storage, file sharing by link, and 30-day file version history.
It supports up to 3 devices.

## Pro plan

The Pro plan costs $12 per month or $120 per year. It includes 2TB of storage, 180-day file
version history, unlimited devices, and SMS and app-based two-factor authentication.

## Business plan

The Business plan costs $20 per user per month, with a minimum of 3 users. It includes 5TB of
pooled storage per user, an admin console, single sign-on (SSO) via SAML, and 1-year version
history.

## Changing plans

You can upgrade at any time from Settings > Billing; the price difference is prorated to the
day. Downgrades take effect at the end of the current billing period.
