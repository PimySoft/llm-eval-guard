# Sharing and files

## Sharing links

Any file or folder can be shared with a link. Pro and Business links can also have a password
and an expiry date.

## Shared folders

Shared folders count against the storage quota of the folder owner only, not the members.

## Deleted files

Deleted files stay in the trash for 30 days on Free and Pro, and 90 days on Business, before
they are permanently deleted.

## Offline access

The desktop and mobile apps can mark files as available offline; changes sync automatically
when the device reconnects.
